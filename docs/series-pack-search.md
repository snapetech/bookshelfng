# Series pack search

Use the search button in an author's series list to search configured indexers
for releases matching that series title. BookshelfNG keeps the search scoped to
the current author and its books, then sends a grabbed release through the
normal download queue.

When the files are ready, use Manual Import to review the pack. Manual Import
shows each file and lets you choose its book and edition, so a single archive
can contain multiple books without assigning every file to one guessed title.

The search is interactive and does not start background searches or add books
to the library automatically. Review the mapped files before importing them.
